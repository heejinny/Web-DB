# 웹 DB 프로그래밍

웹 DB 프로그래밍 수업에서 학습한 Node.js 기반 웹 애플리케이션 개발 실습을 정리한 저장소입니다.

Express를 활용한 서버 구축과 MySQL 데이터베이스 연동을 중심으로 로그인 및 세션 관리, 사용자 권한 처리, 쇼핑몰 및 게시판 기능, 파일 업로드 등의 웹 개발 과제를 수행했습니다.

## 주요 학습 내용

- **서버 개발:** Node.js와 Express를 이용한 웹 서버 및 라우팅 구성
- **데이터베이스 연동:** MySQL을 활용한 데이터 저장 및 조회
- **로그인 및 세션 관리:** 쿠키와 세션을 활용한 사용자 인증
- **권한 관리:** 사용자별 접근 및 관리 기능 실습
- **웹 서비스 구현:** 쇼핑몰, 게시판 등 CRUD 기능 구현
- **파일 업로드:** Multer를 활용한 파일 업로드 실습

## 기술 스택

- JavaScript
- Node.js
- Express
- MySQL
- EJS
- HTML / CSS

## 실행 방법

각 실습 프로젝트 폴더에는 `package.json`이 포함되어 있습니다.

1. 실행하려는 실습 폴더로 이동합니다.
2. 터미널에서 `npm install`을 실행합니다.
3. 필요한 패키지를 설치한 후 프로젝트를 실행합니다.
